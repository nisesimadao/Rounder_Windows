# Rounder for Windows FAQ

## Rounderは何をしていますか？

選択したディスプレイの四隅に、小さなクリック透過の最前面オーバーレイを配置しています。Windowsのシェルやディスプレイドライバー自体は変更しません。

## 管理者権限は必要ですか？

不要です。通常ユーザー権限で動作します。

## 画面収録やアクセシビリティ権限は必要ですか？

不要です。Rounderは画面内容を読み取りません。

## トレイアイコンを隠したら設定を開けなくなりました

`Rounder_Windows.exe` をもう一度起動してください。既存のRounderプロセスがSettingsを開きます。二重起動はしません。

## ログイン時に設定画面が開いてしまいますか？

開きません。自動起動は `--background` 付きで行われ、バックグラウンドで静かに起動します。

## すべてのモニターをオフにできますか？

できます。Displaysで全項目をオフにすると、Rounderは起動したままオーバーレイだけを表示しません。設定は次回起動後も保持されます。

## 新しいモニターを接続したらどうなりますか？

新しく検出されたモニターは既定で対象になります。以前に手動でオフにした既存モニターの選択状態は保持します。

## 排他フルスクリーンでも表示されますか？

通常のデスクトップやボーダーレスフルスクリーンではtopmostを維持しますが、セキュアデスクトップ、ロック画面、一部の排他フルスクリーンアプリより上には表示できない場合があります。

## 設定はどこに保存されますか？

`%AppData%\Rounder\settings.json` と `%AppData%\Rounder\presets.json` です。

## Release版に.NET Runtimeは必要ですか？

GitHub Releasesの単一EXE / Installerはself-containedなので不要です。ソースからビルドする場合は.NET 9 SDKが必要です。
