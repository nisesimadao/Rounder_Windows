# Rounder for Windows FAQ

## Rounder は何をしていますか？

選択したディスプレイの四隅に、小さなクリック透過オーバーレイを配置します。
Windows のシェルやディスプレイドライバー自体は変更しません。

## 管理者権限は必要ですか？

必要ありません。
通常ユーザー権限で動作します。

## 画面収録やアクセシビリティ権限は必要ですか？

必要ありません。
Rounder は画面内容を読み取りません。

## トレイアイコンを隠したら設定を開けなくなりました

`Rounder_Windows.exe` を再度起動してください。
既存の Rounder プロセスが Settings を開きます。
二重起動はしません。

## ログイン時に設定画面が開いてしまいますか？

開きません。
自動起動では `--background` を付けて起動し、設定画面を表示せずバックグラウンドで動作します。

## すべてのモニターをオフにできますか？

できます。
Displays ですべての項目を無効にすると、Rounder は起動したままオーバーレイだけを非表示にします。
設定は次回起動後も保持します。

## 新しいモニターを接続したらどうなりますか？

新しく検出したモニターは既定で対象にします。
以前に手動で無効にした既存モニターの選択状態は保持します。

## 排他フルスクリーンでも表示されますか？

通常のデスクトップやボーダーレスフルスクリーンでは topmost を維持します。
ただし、セキュアデスクトップ、ロック画面、一部の排他フルスクリーンアプリより前面には表示できない場合があります。

## 設定はどこに保存されますか？

`%AppData%\Rounder\settings.json` と `%AppData%\Rounder\presets.json` に保存します。

## Release 版に .NET Runtime は必要ですか？

GitHub Releases の単一 EXE と Installer は self-contained なので、別途 .NET Runtime をインストールする必要はありません。
ソースからビルドする場合は .NET 9 SDK が必要です。
