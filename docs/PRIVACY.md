# Privacy

Rounder for Windows is a local desktop utility.

- It does not capture or inspect screen contents.
- It does not request microphone, camera, location, accessibility, or screen-recording permissions.
- It does not send analytics, telemetry, settings, presets, or identifiers over the network.
- Settings and presets are stored locally under `%AppData%\Rounder`.
- If **Launch at login** is enabled, Rounder writes only its startup command to `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

Opening the GitHub link in the About page launches the default browser.
